The Geometry of Machine Reasoning — progress since the steering vectors

Per-behaviour structure, causal steering, and the post-training origin of safety reasoning · model: DeepSeek-R1-Distill-Qwen-1.5B

thesis 69pp · compiles clean all declared gates run or fired E8 · E9 · E10 · pt01–12 · R0–R3 executed gpt-oss pilot stopped at κ gate

Unifying claim (now the thesis spine) Post-training spends entropy in the decoding distribution, not in representational geometry. Safety SFT translates the representation without restructuring it; RLVR compresses behaviour over unchanged geometry; collapse is rescued by decoding entropy, not state noise; and a targeted steering “pump” trades entropy for value more efficiently than temperature.

Geometry: low-dimensional and flat

replicated ×3

Each reasoning behaviour occupies a compact region of the 1536-D stream; apparent curvature was an artefact.

  • Intrinsic dim ≈ 6–8 per behaviour vs linear span 40–80; replicates across three annotators despite label agreement of only κ 0.35–0.44.
  • Curvature = within-chain autocorrelation: one point per chain → ratio ≈ 1.0 (well-powered negative). Flatness licenses every linear instrument used downstream.
  • Specificity 2/4: backtracking & uncertainty own their subspaces (p < .001); adding-knowledge null everywhere (p = 1.0) — content is distributed, control moves are localised.

Layer attribution

mid layers

Naive attribution patching pointed at L27 for everything — a read-out-proximity artefact, caught three separate times.

  • Faithful gradient attribution: bt L17 · unc L15 · ex L15 · ak L17 — recovers Venhoff’s published layers 3/4 with a different annotator.
  • Mid-vs-late settled by free-generation steering outcome; DAS grounding controls later confirmed L17 and exposed L27 as an optimiser trap. Any logit-proximal metric must be validated behaviourally.

Steering (E8): one real handle

preliminary

Against energy-matched random floors, exactly one behaviour is causally steerable: backtracking.

  • Δ_floor +0.054 single / +0.070 k5 (Holm p = .002); survives count and per-1k endpoints; behaviour-specific (+73% own-vs-other).
  • Example-testing effect = length-dilution artefact (count endpoint p = .27); adding-knowledge null, as geometry predicted; uncertainty under-powered.
  • No manifold advantage: subspace ≈ the same vector (cos 0.965). Caveat: builder-annotator scored; non-builder band budget-blocked.

Collapse (E9): the loop attractor

bidirectional

A pre-existing “Wait, maybe…” whirlpool (34% of vanilla chains); steering moves the state relative to it.

  • Backtracking is a two-way handle: ablate → collapse 24%, boxed answers 2–4× (“overthinking tax”); amplify → 58–64%, boxed 0.00. Generic damage rejected both signs.
  • Temperature T = 0.6 rescues 75–100%; state-noise of any geometry rescues nothing. The rut is the state↔text feedback cycle — only the sampler can break it.
  • Branch points invisible in token entropy: forks are decided in the state before the logits show it.

Causal basis (E10, DAS)

confirmed

The causally-trained axis is a different object from the correlational steering vector — and far stronger.

  • 1-D DAS frame @ L17 transfers +0.649 vs diff-of-means +0.048 (≈13×; CI [+0.54, +0.67]), nearly orthogonal to it (cos ≈ 0.2).
  • Grounding controls caught L11/L27 as optimiser-carved illusions (coord-AUC 0.36 / 0.21) — raw transfer would have picked L27.
  • Grounded causal width ≈ 2-D inside the 6–8-D envelope. Explains the E8 manifold null: occupancy ≠ causation.

Safety post-training: translate, don’t rewire

fully gated

LoRA/full-FT on STAR-1 (doses 100/300/1000) vs size-matched controls, 3 seeds, + DPO/GRPO — all measured on byte-identical generic reasoning text.

  • No rotation (sub-degree), no contraction; one global translation ≈ 5% of norm whose direction is content-determined: cos→STAR1 0.57–0.59 safety vs 0.14–0.18 control; seeds 0.989–0.994; annotator-swap cos 0.999.
  • Method-dependent signature: SFT sharpens (dH −0.010) and translates; DPO on the same data moves a different axis (cos 0.16–0.20) and raises entropy (+0.0145, safety-specific); GRPO ≈ no-op.
  • Fine-tuning re-weights the policy over an intact representational substrate — a fingerprint of method, not just data.

Creativity / entropy (R0–R3)

R3 provisional

RLVR compresses behaviour, not representation; targeted entropy beats indiscriminate entropy.

  • R1: distillation installs deliberation (0.14 → 12 bt-cues/1k); RLVR re-compresses it — entropy, length, diversity all fall while matched-text geometry is untouched (ΔPR ≈ 0).
  • R3 (3,584 chains): at matched strategy entropy the backtracking “pump” retains more accuracy than the temperature “thermostat” (+0.016, CI [.013, .019], 24/25 grid pts); T = 1.2 burns accuracy 0.88 → 0.56. Lexical strategy labels — sign provisional.
  • The loop jam is a low-entropy state (0.39 vs 0.86 nats): being stuck is a rut, not a storm.

Predictive geometry & the gpt-oss gate

gated stop

Value information is occupancy, not order; the gpt-oss pilot killed itself as designed.

  • Correctness = state-occupancy, confirmed 3 independent ways (order-blind models beat the trained GRU). Linear forward map: real, onset-specific (p ≈ 1e-68) but small (3–7% recovery).
  • gpt-oss-20b pilot: 100 chains, 3-judge annotation — harm-recognition κ 0.62 citable, but decision κ 0.22 < 0.4 → pre-registered kill criterion fired; stopped before geometry spend. Abstract deliberative labels have no shared textual anchor.
